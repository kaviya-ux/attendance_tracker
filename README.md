# Attendance Tracker

##  About

Attendance Tracker is a simple web application designed to record and manage attendance easily. It helps users track attendance details in a clear and organized way.

##  Features

* Add and manage attendance records
* Mark students as Present or Absent
* View attendance details
* Simple and user-friendly interface
* Responsive design

##  Technologies Used

* HTML
* JavaScript
* Tailwind CSS

##  How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start tracking attendance.

## 🎯 Purpose

This project was created to practice frontend development and JavaScript concepts while building a useful attendance management application.
